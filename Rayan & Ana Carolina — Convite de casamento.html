Como editar e publicar esta página

Instruções claras para os noivos ou desenvolvedores adaptarem e colocarem o convite no ar:

  1. 1 Alterar os dados no objeto CONFIG: No início da tag <script> deste arquivo, há o objeto JavaScript CONFIG. Altere ali os nomes, a data, a hashtag, o telefone, os links e as frases sem precisar caçar pelo código.
  2. 2 Personalizar textos e horários sugeridos: Edite a lista timeline dentro de CONFIG com os horários e títulos definitivos de cortejo, jantar e festa assim que confirmados com os cerimonialistas.
  3. 3 Trocar links do mapa, Lejour e contato: Substitua as URLs do Google Maps, os links do Lejour (lista de convidados e presentes) e o número do WhatsApp pelos canais atualizados nos campos designados de CONFIG.
  4. 4 Conectar localStorage a um backend para dados compartilhados: Atualmente os dados de RSVP, recados e presentes ficam no localStorage deste dispositivo. Conecte as funções salvarRsvpNoServidor e salvarRecadoNoServidor ao seu endpoint/API (ex.: Firebase, Supabase, Google Sheets via Webhook ou Node.js) para sincronização multi-dispositivo.
  5. 5 Publicar o HTML no Netlify ou GitHub Pages: Como este projeto é 100% estático em um arquivo autocontido, basta arrastar o arquivo ou fazer upload do repositório para o Netlify Drop, GitHub Pages ou Vercel gratuitamente para obter o link final na internet.
